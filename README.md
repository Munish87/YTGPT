# YTGPT

A lightweight, browser-based YouTube thumbnail maker inspired by Pikzels.

## Features
- Generate AI backgrounds from text prompts (Bytez + Google Imagen 4.0)
- Upload a background image (or sketch)
- Upload a face cutout image
- Add and style headline text
- Position and scale the face overlay
- Export final thumbnail as PNG

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.
